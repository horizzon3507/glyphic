# Glyphic

Convert images into ASCII art in a retro CRT terminal aesthetic. Built with React, Vite, TypeScript and Tailwind CSS.

## Features

- Image → ASCII conversion with adjustable resolution and contrast
- Multiple character sets (Standard, Simple, Blocks, Binary, Matrix, Detailed)
- Color mode, invert, custom text/background colors and font family
- Copy to clipboard or export as PNG/JPG
- CRT scanlines and flicker effects

## Developing

```sh
bun install
bun dev
```

## Building

```sh
bun build
bun preview
```
